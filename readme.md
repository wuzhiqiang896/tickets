为什么：需要知道机器人是否有效以及站点是否发生了变化。
实现：
实施全面的日志记录。
创建“健康检查”脚本，在销售时间之外定期（例如每天）运行，以测试登录、基本导航，甚至端点可访问性，以主动检测网站更改。
为严重故障或成功预订设置警报（例如，电子邮件、Slack）。
